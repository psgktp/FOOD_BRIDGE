1. Smart Matching Formula

Multi-Factor scoring weights:

MatchScore = 0.35·Dist + 0.30·Urgency + 0.20·Capacity + 0.15·Diet
2. 4-Tier Urgency Decay
  • Critical (<2h): Red pulsating alert
  • Urgent (2–4h): Yellow priority banner
  • Moderate (4–8h): Blue normal queue
  • Stable (>8h): Green batch routing

Dual-stage QR handshakes eliminate fraudulent meal claims, protect donors from liability, and produce tamper-evident audit logs.
